# Zara.com — Next.js Clone

A faithful front-end replica of [Zara.com](https://www.zara.com), built with Next.js 14 and TypeScript as a learning exercise.

[![CI](https://github.com/xabierlameiro/zara.com/actions/workflows/ci.yml/badge.svg)](https://github.com/xabierlameiro/zara.com/actions/workflows/ci.yml)

> **📚 Educational project**: This is a UI/UX study and Next.js practice project. It is not affiliated with or endorsed by Zara or Inditex.

## Stack

| Layer           | Choice              |
| --------------- | ------------------- |
| Framework       | Next.js 14          |
| Language        | TypeScript          |
| Testing         | Jest                |
| Package manager | npm                 |

## Getting started

```bash
git clone https://github.com/xabierlameiro/zara.com.git
cd zara.com
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Script          | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm run lint`  | ESLint                   |
| `npm test`      | Jest unit tests          |
